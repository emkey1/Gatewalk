# Random World Explorer v6

This version starts fullscreen to avoid Godot restoring a tiny per-project window.

## Window Behavior

The game requests fullscreen in both project settings and startup code. If you need a windowed mode while testing, press `F10` to force a centered 1280x720 window. Press `F11` to toggle between fullscreen and the 1280x720 windowed fallback.

On macOS, Godot may restore stale window state during startup, so fullscreen is also requested after the main scene is ready.

## World Generation

The initial world is generated at runtime from a saved seed. It uses a larger terrain grid with layered height noise, a carved river valley, vertex-colored biomes, water, denser trees and rocks, wildflower patches, deterministic fantasy wonders, glowing crystal clusters, scattered ancient ruins, and world gates.

Worlds are saved to `user://world_graphs.json`. On first launch the game creates and saves a default world, then reloads that saved world on later starts. The menu can create additional world slots, and each slot stores its generated maps plus the gate connections between those maps. A connected map is only generated and saved when its gate is first activated.

Trees, rocks, crystals, ruin pillars, ruin platforms, and gate posts are solid. You can run into them, and ruin platforms can be walked on.

## Objective

The old Atlas of Gates broke apart, leaving whole worlds adrift behind forgotten portals. You are a field cartographer for the last observatory, sent to cross the gates, name what remains, and stitch the lost routes back into a living map.

The objective is to restore the Atlas of Gates. Explore each map, discover wonders, ruins, and gates, then use gates to expand the saved atlas into newly generated connected maps.

The game tracks atlas progress rather than an arcade score: discovered worlds, maps, gates, ruins, and wonders are the measure of progress. This keeps the emphasis on curiosity, navigation, and building a personal record of strange places.

The menu includes a 3D Atlas Graph. It is intentionally abstract: only gate points float in space, and discovered gate connections are color-coded lines between those points. Four nearby points represent the gates in one discovered map. The current map's gate cluster is highlighted, and each cluster label shows local discovery completion.

Gate shimmer is visible from both sides. Its color is generated from the connected map seed, so recurring colors become clues about what kind of world lies beyond. Unvisited gates use the same deterministic preview seed that will be assigned when the gate is first activated.

Fantasy wonders are generated by `scripts/WonderGenerator.gd` from `world_seed + wonder position + salt` using a small stable PRNG, not Godot's built-in random stream. Only the map seed and deterministic placement rules are needed to recreate the same moon gates, crystal spires, runestone circles, and floating shrines on reload.

Going underwater now changes the visual atmosphere and movement feel. The water surface remains visible from below, and movement slows into a simple swim state where `Space` swims upward.

The HUD shows atlas totals, local map discoveries, current position, distance to the map edge, and recent discoveries. Each generated map also has invisible edge barriers plus a fall recovery fallback in case the player gets outside the playable terrain.

The HUD is one compact integrated panel (half the screen width/height of earlier versions) with atlas progress, a slim sprint stamina bar, and an overhead minimap. The minimap shows the player plus discovered gates, ruins, and wonders for the current map.

Moon Gates lead to a shared moon map for the current world. The moon has no water, lower gravity, 4x jump strength, darker lunar terrain, a star field, a distant blue world on the horizon, subtle horizon glow, and floating benign lichen bodies that slowly drift in random directions. Glass craters are scattered across the lunar surface — translucent cyan basins ringed by rocky debris and crystal shards, each registered as an atlas discovery.

Procedural ambient audio is generated at runtime: a low drone on the moon, a deep hum near water, and a shimmering spatial hum at each gate. Drop `.ogg`, `.mp3`, or `.wav` files into `audio/music/` for background music (selected randomly per map load).

## Setup

1. Install Godot 4.4 or newer for macOS.
2. Unzip this folder.
3. Open Godot.
4. Choose **Import**.
5. Select `project.godot`.
6. Open the imported project.
7. Open `scenes/main.tscn`.
8. Press Play.

## Controls

- `W`, `A`, `S`, `D`: move forward, left, back, and right
- Mouse: look around while the cursor is captured
- `Shift`: sprint while moving
- `Space`: jump, or swim upward underwater
- `Esc`: release or recapture the mouse cursor
- `M`: open the world menu
- `F10`: force 1280x720 windowed mode
- `F11`: toggle fullscreen/windowed mode

## If the window is still tiny

In Godot, use:

Project > Project Settings > Display > Window

Set:

- Size / Viewport Width: `1280`
- Size / Viewport Height: `720`
- Size / Mode: `Fullscreen`
- Stretch / Mode: `canvas_items`
- Stretch / Aspect: `expand`

Then close and reopen Godot. Godot sometimes stores per-project window state. Because of course it does.
